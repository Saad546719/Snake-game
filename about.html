🐍 About Snake Game

یہ ایک سادہ اور دلچسپ Snake Game ہے جو HTML, CSS اور JavaScript کی مدد سے بنایا گیا ہے۔ اس گیم میں کھلاڑی سانپ کو کنٹرول کرتا ہے، خوراک کھاتا ہے اور اس کا سائز بڑھتا جاتا ہے۔

اس پروجیکٹ کا مقصد ایک کلاسک گیم کو دوبارہ زندہ کرنا ہے تاکہ صارفین بغیر کسی انسٹالیشن کے براؤزر میں کھیل سکیں۔
